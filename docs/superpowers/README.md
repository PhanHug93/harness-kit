# Superpowers Development Records

Development records for harness-kit itself.

- `specs/` contains the only development artifacts tracked by Git. Specs are
  living documents while their effort is open and become immutable historical
  records when it closes.
- `plans/`, `reviews/`, `archive/`, and every other development-record
  directory are local-only. Never stage or push them.
- The root `README.md` in this directory is tracked only to define this policy.

Before committing, verify that the branch diff contains no development
artifact outside `docs/superpowers/specs/`.
